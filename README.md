# Creswell Colliery 3D

Interactive 3D model and walk-through of the Threequarter seam workings at Creswell Colliery, Derbyshire, at abandonment (20 September 1991).

- **3D model:** seam workings at true level, shafts and insets, cutaway sections, grid references, measuring tool.
- **Walk the mine:** Street View-style walk through about 74 km of roadways traced from the plans, with a cage ride down No. 2 Shaft.

Built from British Coal Corporation abandonment plans (catalogue EM1404, sheets SK4870–5471, 1:2500). Roadway fit-out (arches, conveyors, rails) is illustrative. Seam levels are interpolated from spot levels on the plans.

Static site: open `index.html` through any web server (GitHub Pages serves it as-is).
